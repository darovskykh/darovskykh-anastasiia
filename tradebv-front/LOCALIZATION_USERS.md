Добавлена секция `users` с переводами:

Файл `src/pages/UserManagement.tsx` обновлён для использования переводов через хук `useLanguage()`.

## Использование

Локализация работает автоматически в зависимости от выбранного языка:

```typescript
const { t, language } = useLanguage();

// Простой перевод
t('users.title') // "Управління користувачами" или "User Management"

// Перевод с параметрами
t('users.toasts.userCreatedDesc', { username: 'john@example.com' })
// "Користувач john@example.com успішно створений."

// Вложенные переводы
t('users.roles.admin') // "Адміністратор" или "Administrator"
```

## Динамическое форматирование

### Даты
Даты форматируются в соответствии с выбранным языком:
```typescript
const locale = language === 'uk' ? 'uk-UA' : 'en-US';
date.toLocaleDateString(locale, options);
```

### Относительное время
- UK: "5 год тому", "3 дн тому", "Зараз", "Ніколи"
- EN: "5 hr ago", "3 days ago", "Now", "Never"

## Добавление новых переводов

Чтобы добавить новый перевод:

1. Добавьте ключ в `src/locales/uk.json`:
```json
{
  "users": {
    "newKey": "Новий текст"
  }
}
```

2. Добавьте английский перевод в `src/locales/en.json`:
```json
{
  "users": {
    "newKey": "New text"
  }
}
```

3. Используйте в компоненте:
```typescript
t('users.newKey')
```

## Тестирование

Для проверки локализации:

1. Переключите язык в навигации (🇺🇦 Українська / 🇺🇸 English)
2. Проверьте все элементы страницы
3. Создайте пользователя и проверьте уведомления
4. Проверьте модальные окна и действия

Все тексты должны мгновенно переключаться при смене языка!
